# Wilkinson Electrical Services Website

A professional, responsive website for Wilkinson Electrical Services - a 5-star rated electrician business in Norwich.

## Features

- ✅ Professional, modern design
- ✅ Fully responsive (mobile, tablet, desktop)
- ✅ Services showcase (8 services)
- ✅ Customer reviews section (26 verified Google reviews)
- ✅ Business information and hours
- ✅ Smooth scrolling navigation
- ✅ Fast loading (static HTML/CSS/JS only)

## Files

- `index.html` - Main website structure
- `styles.css` - All styling and responsive design
- `script.js` - Interactivity and smooth scrolling
- `README.md` - This file

## Setup Instructions

### 1. Deploy to GitHub Pages (Free)

1. Go to your repository settings
2. Scroll to "GitHub Pages" section
3. Select "main" branch as source
4. Click Save
5. Your site will be live at `https://robin1332.github.io/wilkinson-electrical`

## Deployment Options

### GitHub Pages (Free)
- Already configured in this repo
- No cost, automatic HTTPS

### Netlify (Free tier available)
1. Go to https://netlify.com
2. Drag and drop this repository folder or connect GitHub
3. Deploy (automatic)
4. Get a free subdomain

### Vercel (Free tier available)
1. Go to https://vercel.com
2. Import this GitHub repository
3. Deploy (automatic)

- Mobile (480px - 767px)
- Small mobile (< 480px)

## Customization

To update content:
- **Business info**: Edit index.html (phone, address, hours)
- **Services**: Update service cards in Services section
- **Reviews**: Edit review text in Reviews section
- **Colors**: Modify CSS variables in styles.css
